# Clarify Message

把散落在消息里的重要事项和截止日期整理出来，并提醒你及时行动。

> 项目状态：构思与规划阶段。目前仓库只有这份 README，还没有可运行的程序。

## 为什么做这个项目

重要信息可能藏在聊天、邮件或公告中。消息多的时候，即使看过也容易忘记具体要做什么、什么时候截止。Clarify Message 希望把一段信息变成清楚、可确认的行动项。

最初的使用场景是：因为没有及时查看手机消息而错过截止日期。

## 想实现的最小版本

1. 用户粘贴一条消息，或导入一小组示例消息。
2. 程序找出需要行动的内容，提取事项、截止时间和原文依据。
3. 用户检查并修改结果，尤其是含糊的日期或时间。
4. 用户确认后，程序按设定时间提醒。
5. 用户将事项标记为完成；未确认的紧急事项可以再次提醒。

示例：

> “项目报名请在周五 18:00 前提交表格。”

整理为：

| 字段 | 示例 |
| --- | --- |
| 要做什么 | 提交项目报名表格 |
| 截止时间 | 周五 18:00（需结合消息日期确认具体日期和时区） |
| 原文依据 | “请在周五 18:00 前提交表格” |
| 状态 | 待用户确认 |

**核心原则：** AI 可以帮忙筛选和提取，但不确定的时间必须由用户确认；提醒要有完成或已读状态，避免只制造更多通知。

## 项目流程

```text
消息输入 → 识别重要信息 → 提取行动项和截止时间
       → 用户确认 → 保存事项 → 定时提醒 → 标记完成
```

第一版先支持**手动粘贴消息**。接入邮箱、聊天平台或手机通知会增加授权、隐私和平台限制，等基本流程跑通后再决定是否添加。

## 当前限制与安全约定

- 目前没有登录、账号、数据库、通知服务或 AI 模型接入，也没有可运行演示。
- 不要把邮箱密码、API Key、访问令牌或真实私人消息提交到公开仓库。
- 如果以后需要连接第三方账号，应使用该平台提供的正式授权方式，并只申请必要权限；具体方案要在接入时设计。
- 识别出的截止时间可能有误，特别是“明天”“下周五”等相对日期，所以必须保留原文并让用户确认。
